# Atividade – 04/08

## 1. Quem utilizará o sistema?
O sistema será utilizado pelos professores e pela coordenação do curso.

## 2. Requisitos Funcionais
- Listar alunos.
- Editar alunos.
- Agrupar alunos.

## 3. Requisitos Não Funcionais
- O sistema deverá responder às solicitações em até 1 segundo.
- O sistema deverá criar um registro de log diariamente.

## 4. Explique, em poucas palavras, por que é importante levantar os requisitos antes de desenvolver um software.
O levantamento de requisitos é importante porque permite definir o escopo do projeto, compreender como o sistema deverá funcionar e atender às necessidades dos usuários. Além disso, ajuda a evitar erros, mudanças desnecessárias e retrabalho durante o desenvolvimento.
